# Изменения

Каждая версия начинается со строки `## <версия> — <дата>`. Уведомление об обновлении показывает пункты всех
версий новее установленной. Если версия меняет базу данных, в пункте есть слово «миграция».

## 1.1.0 — 2026-11-25

- Новый вид журнала: события фразами по дням, «было → стало», вкладки со счётчиками, один поиск по логину,
  IP и тексту, тревоги заметнее всего остального; форма входа с понятными ошибками и числом оставшихся попыток.
- Журнал во всю ширину страницы, форма входа по центру; цвета вкладок и кнопок не зависят от темы.
- Просмотр и обновление страницы больше не пишутся в журнал: открытие записывается один раз при вводе паролей.
- Если пароль журнала в audit_log.yml не задан или остался пример REPLACE, аудитор видит понятное сообщение
  вместо «неверный пароль».
- Проверка обновлений: раз в сутки модуль сверяет версию с GitHub и показывает уведомление внутри журнала
  (только аудиторам); проверка из консоли: `rake redmine:audit_log:check_update`.
- Нейтральное описание в списке модулей, автор и ссылки на GitHub.

## 1.0.0 — 2026-11-25

- Первая версия: журнал входов и административных изменений, доступ по списку и двум паролям,
  цепочка хешей, тревоги. Создаёт таблицу audit_log_entries (миграция).
